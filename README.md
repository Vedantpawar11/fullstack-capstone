# Cars Dealership Capstone Project

**Repository Name:** fullstack-capstone

**Project Name:** Cars Dealership

## Project Description

The Cars Dealership application is a full-stack web application developed as part of the Full-Stack Development Capstone Project.

The application allows users to explore car dealership locations, view dealership details, register and log in, and submit reviews.

## Technologies

* Python
* Django
* React
* REST APIs
* Git and GitHub

## Project Objectives

* Display dealership information.
* Allow users to register and log in.
* Enable users to view dealership reviews.
* Allow users to submit dealership reviews.
